# FULL_REZZ 3.0 - Quick start

Guides refreshed 15 October 2026; download revision 2026-10-14.3. Windows 10/11 x64 release candidate; native Windows acceptance remains pending.

1. Download FULL_REZZ_3.0_Recovery_Tools.zip and all 15 matching FULL_REZZ_3.0_Installer_NN_of_15.zip files into a new folder. Extract only the recovery tools into that folder; leave the installer ZIPs zipped. Run Assemble_Installer.cmd. It verifies downloads and reconstructs FULL_REZZ_3.0_Offline_Windows_x64_Setup.exe. Do not mix revisions.
2. Run the reconstructed installer and choose its language/program folder. It includes the runtime, models, fonts and codecs. Allow about 15 GB free space for downloads, assembly and installation; keep the installer for repair. No external Python, Node, model service, API key or first-run download is required.
3. Open FULL_REZZ. Keep the workspace outside the installed program. Select Character companion and the intended stable profile. The supplied Rebecca pack is one unmeasured 2D cel; Studio Unit is an original neutral 3D demonstration.
4. Import chat history with explicit role mappings where needed. Use Send and speak for a new local reply and speech. CPU generation may take minutes. A speech failure keeps the reply; Retry speech uses that same turn.
5. Select supported 2D/3D views and inspect camera/action controls. Export companion movie at 60, 120 or 240 fps. Audio energy drives the mouth. Output fps does not reconstruct missing poses or unseen anatomy.
6. Review voice ratings, geometry and frame flags separately. Back up the editable workspace before moving or upgrading. Uninstall preserves the separate workspace.

F5 conditioning supports English/Mandarin. Generic eSpeak speech is experimental in twelve languages and does not imitate a character. Interface/reply/transcription/synthesis choices are independent. Human likeness and art review remain required.

Replit: import FULL_REZZ_3.0_Replit_Source_Core.zip with main.py and .replit at the project root. Give TASK_QUERY.md to Agent in the receiving project. The starter inspects data without inference. A browser host needs its own presenter; Qt runs natively. Read the Replit integration guide and complete user guide supplied with this set.

Troubleshooting: keep startup_error.log and failed receipts. Assembly logs appear beside the downloads; a missing or damaged ZIP is named before assembly stops. Use the matching complete installer for repair. Clean Windows installation, device playback, GPU pacing, repair/upgrade and uninstall still require target-machine testing.
