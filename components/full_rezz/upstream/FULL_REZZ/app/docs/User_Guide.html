FULL_REZZ 2.0

Install and get started

Local Windows package

FULL_REZZ 2.0 targets Windows 10/11 x64. The installer includes Python, Qt, audio decoders and all speech models. No separate Python, Node, browser, FFmpeg, account, model download or service is needed after installation. Plan for 16 GB RAM and 12 GB free disk space. CPU synthesis can take minutes; this is not a real-time avatar.

Assemble the installer

Download all four FULL_REZZ_Installer_Part ZIP files. Windows delivery is split because the complete installer exceeds the file delivery limit. Extract every ZIP into the same empty folder. Double-click Assemble_Installer.cmd in that folder. It joins the fragments and checks SHA256 before launching the single FULL_REZZ_2.0_Offline_Setup.exe. Retain the four fragments until verification succeeds.

Install and launch

Run the installer as your own user. Choose the installation folder and shortcuts, then open FULL_REZZ. Default install: %LOCALAPPDATA%\Programs\FULL_REZZ. This release is unsigned. A native Windows install and launch test has not been performed; the acceptance procedure on page 4 remains required.

Where projects live

Project data uses %LOCALAPPDATA%\VoiceProfileStudio to preserve continuity with earlier releases. Imported audio, authored profiles, sources, exports and render receipts remain there. Back up this entire folder with FULL_REZZ closed. Uninstall removes program files and retains project data.

First session

Open Expression & export and choose Load bundled Rebecca, or import your reference ZIP. Inspect the restored recording, region text, review status and source documents. Select the voice profile, enter a short statement, choose the reference style and select Render local speech. Listen to the speech and its actual selected reference before saving a review.

Prepare a reliable voice reference

Import and identify

Import WAV, FLAC, MP3, OGG, M4A and supported audio/video containers. Limits: 250 MiB upload, 30 minutes, eight channels and 512 MiB decoded audio. Original files remain preserved. Reference mode treats a recording as one voice; channels select physical channels; automatic grouping produces anonymous ECAPA energy-window/cosine groups, not verified identities.

Transcript and regions

Bundled tiny.en transcription is English only and can get names and words wrong. Correct the words manually. Set region start/end, voice label, channel, style and purity review, then Save region edits. Bind the speaker to a character profile. Speaker and character drafts survive switching, but must be saved before export or synthesis.

Overlap and cleanup

Separation accepts excerpts up to 30 seconds and outputs two anonymous 8 kHz estimates. Listen for bleed and artifacts. Cleanup is reversible: DC removal, rumble filtering, peak level, boundary fades and optional noise attenuation. A noise-only excerpt must contain no voice or music. Compare Original and Cleaned; conversion cannot repair clipped or missing source bandwidth.

Measurements and review

Signal screening reports native-rate levels, clipping, DC and quiet-frame contrast. Band energy reports bass (20-250 Hz), mid (250-2000 Hz), treble (2000-8000 Hz) and upper frequencies where available. These are acoustic measurements, not emotion, identity or likeness scores. A floating signal above full scale is reported separately from PCM clipping.

Choose useful conditioning

Use a clean, reviewed single-voice region of 3-12 seconds with its exact spoken words. Requested style selects an available reference label; it does not guarantee emotional performance. Short, noisy, mixed or poorly transcribed references can reduce pronunciation and resemblance. The bundled Rebecca reference is source-attributed; performer likeness and purity have not been verified by listening.

Render, review and preserve context

Speech controls

Enter 1-500 characters. Rate: 0.5-2.0. Pitch: -12 to +12 semitones. Volume: -20 to +6 dB. Choose 16 sampling steps for a draft or 32 for fuller sampling; seed is 0-2147483647. Estimated output is capped at 30 seconds. Reference words override the saved annotation; if both are missing, local ASR is used and marked unreviewed.

Output and review

F5-TTS v1 Base and Vocos render locally on CPU. Output is 24 kHz FLOAT32 WAV with peak headroom and 5 ms boundary fades. Download the WAV and JSON receipt. Each receipt records selected reference, words, controls, seed, steps, measurements, authored context and review history. Approve or mark Needs revision after listening. A changed audio hash prevents attaching a review. Approval records judgment; it does not train the model.

Character and engram files

Biography, persona, prompts, scene notes, canonical endpoint and field sources are authored context. Imported source evidence remains separate from authored facts and retrieved claims. Local TXT, JSON, PDF and DOCX documents can be imported. Internet source retrieval is disabled in the packaged offline application. Engram/context files do not implement autonomous reasoning, new knowledge or consciousness.

Export and restoration

Export an immutable reference ZIP with selected profiles, clips, sources, voice logs, character context and quality report. FLOAT32 preserves over-range samples; integer encodings use dither and reject out-of-range audio. Restore packs up to 512 MiB expanded and 10,000 files. IDs are remapped, historical embeddings are retained as history, and the entire original imported ZIP is preserved and included in subsequent exports. Invalid paths, duplicate names or changed reference hashes reject the import transaction.

Animation capabilities

The included 12-second Rebecca sequence contains 720 frames at 60 fps, 23 scheduled body drawings and continuous face/limb motion. Use frame stepping and the 24 fps baseline comparison. This demonstrates an authored 2D animation, not arbitrary image-to-motion generation, unseen poses, accurate anime sidesteps, 3D reconstruction or Studio Trigger production equivalence. Audio-energy mouth animation is not phoneme alignment. New speech is exported separately; this release does not automatically regenerate the demonstration for each new statement.

Acceptance, troubleshooting and licenses

Before calling it a Windows release

On a clean Windows 10/11 x64 machine, disconnect networking. Assemble and install the package; launch from both shortcuts; load Rebecca; play the 60 fps example; import audio; transcribe, group speakers and separate a short excerpt; render a statement; play/download WAV and receipt; save a review; close/reopen; export and restore a ZIP. Uninstall, reinstall and confirm retained project data. Confirm no runtime, model download, external browser or account is requested.

What has been tested

Linux CPU neural inference, loopback API transport, program regression tests, actual 60 fps frame rendering, MP4 decode/timing and installer payload checks are recorded in FULL_REZZ_Audit.md. PE inspection checks declared DLL imports. These checks do not establish native Windows GUI execution, sustained 60 Hz display on your hardware or human listening approval.

If something fails

A model checksum error requires reinstalling from the verified installer. If the data folder is locked, close the other FULL_REZZ instance. If synthesis fails, confirm a saved reviewed 3-12 second reference and its actual words; shorten the statement. Review Needs revision output for pronunciation and artifacts. Close with processing idle before backing up. Keep the installer verification report and local data when reporting a problem.

Quality boundaries

Technical signal checks cannot prove acting quality, voice identity, speaker purity or anime fidelity. Validate those by listening and by comparing against actual licensed motion references. Retain original files and receipts so each judgment can be traced to the exact delivered bytes.
