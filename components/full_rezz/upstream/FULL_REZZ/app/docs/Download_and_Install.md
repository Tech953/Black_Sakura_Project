# FULL_REZZ 3.0 - Download and install

Use all FULL_REZZ_3.0_Setup.partNN files, FULL_REZZ_3.0_Delivery_Manifest.json, Assemble_FULL_REZZ_Installer.ps1 and Assemble_Installer.cmd from the new release. Assemble verifies every transport part and the complete EXE before committing it. Run the one resulting Setup.exe. The installed application includes all runtimes and models and works without Node, external Python or a model service. These download parts are not installed dependencies.

The installer is unsigned. Native Windows installation/startup/audio/GPU/upgrade/uninstall acceptance is still pending. Read User_Guide.md and Release_Audit.md. Older Voice Profile Studio and FULL_REZZ 2.0 parts do not assemble this release.
