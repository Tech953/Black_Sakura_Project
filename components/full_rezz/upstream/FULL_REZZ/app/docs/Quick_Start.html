FULL_REZZ 2.0

Quick start

Install

Download and extract all four installer ZIPs into one folder. Run Assemble_Installer.cmd; it verifies the reconstructed EXE, then starts setup. Install and open FULL_REZZ. No separately installed runtime or online model download is needed.

Restore

In Expression & export, choose Load bundled Rebecca or Import reference pack. Inspect the recording and saved source context. Historical IDs are remapped; original archive bytes remain preserved.

Review the reference

Save a 3-12 second single-voice region, its actual words and a purity review. Bind its voice label to the profile. Compare original and cleaned previews before rendering.

Render and listen

Select the voice, enter a short statement, choose 16 or 32 steps and Render local speech. Listen to both speech and selected reference. Download the WAV and receipt; save Approve or Needs revision notes.

Keep the evidence

Export a reference ZIP, or back up %LOCALAPPDATA%\VoiceProfileStudio with the program closed. Uninstall retains project data. The 60 fps animation example is a fixed authored test, not arbitrary action generation.

Release limits

Windows 10/11 x64 native installation and GUI testing remain pending. F5 weights are noncommercial (CC-BY-NC-4.0). Audio quality and performer likeness require listening review. Full details and acceptance steps are in the user guide.
