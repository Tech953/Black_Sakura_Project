# FULL_REZZ 3.0 — 사용자 안내서

언어 설정은 독립적입니다. 캐릭터는 로컬 응답을 생성하며 자동 설정은 현재 요청의 언어를 사용하도록 지시합니다. 모호한 언어는 ENGRAM에서 확인하세요. 음성 편집기는 대사를 번역하지 않습니다. 아랍어는 오른쪽에서 왼쪽이며 JSON, 경로, 해시와 근거는 유지됩니다.

## 1 오디오 및 구간

익명 군집을 듣고 검토하세요. 중첩이나 인물 식별은 지원하지 않습니다. 채널은 0부터 시작하며 빈칸은 모노 믹스입니다.

1. 오디오/비디오 가져오기
2. 듣기
3. 편집 저장
4. 선택 화자 연결

## 2 프로필 및 출처

알 수 없는 사실과 출처를 유지하세요. 어조와 억양은 상황에 따라 달라지며 스펙트럼과 음높이는 별개입니다. 새 대사는 정사가 아니며 출처의 정체성과 이력은 유지됩니다.

1. 새 프로필
2. 로컬 출처 가져오기
3. 출처에서 초안 작성
4. 프로필 개정 저장

## 3 생성

F5는 영어/표준 중국어 참조 음성을 지원합니다. 일반 음성은 12개 언어에서 실험적이며 캐릭터를 모방하지 않습니다. 아랍어에는 모음 기호가 필요하고 일본어는 예비 지원입니다. 자동 번역이나 엔진 교체는 없습니다.

1. 음성 합성 언어
2. 음성 엔진
3. 테스트 음성 생성

## 4 검토 및 감사

음성을 듣고 다섯 평가 항목을 검토하세요. 텍스트나 신호 검사는 유사성, 발음, 자연스러움, 음질을 승인하지 않습니다. 실패는 이력에 남습니다.

1. 참조 음성 듣기
2. 생성 음성 듣기
3. 발화 내용 재검사
4. 청취 검토 추가

## 5 내보내기 및 백업

내보내기에는 참조 음성, 출처, 전사, 개정, 생성 음성과 감사가 포함됩니다. 백업은 원본을 유지합니다. 빈 폴더에 복원하며 제거 시 별도 작업 공간은 보존됩니다.

1. 참조 패키지 내보내기
2. 편집 가능한 작업 공간 백업
3. 빈 폴더에 백업 복원

## 캐릭터 동반자

1. 채팅 가져오기
2. 전송 및 음성 생성
3. 제작된 2D 뷰
4. 3D 표면
5. 동반자 창 열기
6. 캐릭터 동영상 내보내기

FULL_REZZ companion: local replies are provided by the separate character companion module. See the bundled User_Guide.pdf for imports, rendering, speech and remaining acceptance gates.

처리는 되돌릴 수 있습니다. 원본을 보존하며 잡음 제거에는 잡음만 있는 구간이 필요합니다. JSON과 근거는 원형을 유지합니다.

기술 세부 정보는 원래 언어로 보존됩니다.
