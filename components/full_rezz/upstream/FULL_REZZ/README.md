# FULL_REZZ 3.0

Implemented character/voice/animation companion source for a native offline Windows application and incorporation into your ENGRAM software. The release includes complete-history import, actual local/host dialogue adapters, new speech-driven authored performance, selectable supplied 2D views and real glTF/GLB surface rendering, shared native panels/windows, six-shot camera timing, 60/120/240 fps movie export and retained audit evidence.

The source/runtime is 3.0.0. The legacy dependency-free bridge is 1.0.0, and its old action descriptors retain automatic_reanimation=false. Current conversation uses the separate implemented companion protocol. The starter `python3 main.py` only inspects supplied data; it does not perform inference. Read TASK_QUERY.md for the host incorporation request, docs/COMPANION_INTEGRATION.md for actual adapters and docs/FULL_REZZ_3.0_Product_Audit.md for acceptance status.

The supplied Rebecca pack is one unmeasured 2D cel. It has no supplied 3D body or articulated sidestep. Studio Unit is an original neutral rig used to test actual front/side/rear geometry and camera movement. Import reviewed character artwork/rigs to extend a character. Body-preservation exports retain 40 open artistic flags; no studio-equivalence score is assigned.

The standalone Windows installer is internally complete and contains its runtime and twenty verified speech/text model assets. The Replit import ZIP excludes private runtime/weights, corresponding-source archives and historical duplicate media to remain below 200 MB. The complete source ZIP contains notices and corresponding sources. No signed-in Replit run or unseen ENGRAM repository modification is claimed. Native Windows installation/playback/driver acceptance remains pending.

Current user guide: FULL_REZZ/app/docs/User_Guide.md (also PDF). Current evidence: evidence/product_v3/. Actual new movies/audio: product_exports/. Historical transcript/audit: docs/.
