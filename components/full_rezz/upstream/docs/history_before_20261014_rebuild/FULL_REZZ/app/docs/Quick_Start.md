# FULL_REZZ 3.0 - Quick start

1. Put all installer parts, the delivery manifest and assembly scripts together. Run Assemble_Installer.cmd, then run the verified single Setup.exe.
2. Choose Language settings, then Character companion. Keep the intended stable profile selected.
3. Import a JSON/JSONL, explicitly mapped CSV or reviewed speaker-labeled text chat log. Export full history checks the complete stored archive.
4. Send and speak uses the bundled local text model and your selected speech engine. Retry speech preserves the same stored reply and prior audits.
5. Choose a supplied 2D view or real 3D asset. Missing representations are explicit. The neutral 3D demonstration is not Rebecca's body.
6. Export companion movie at 60, 120 or 240 fps. Inspect the audit JSON and original WAV. Use Animation comparison for the prior and body-preservation movies.
7. Review words, signal checks and human ratings. Finish processing, then back up the workspace. Uninstall retains it.

The full user guide describes formats, model limitations, licensing and troubleshooting. Native Windows acceptance and artistic pose/voice approval remain pending.
